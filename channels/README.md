# Описания версий

Здесь лежат файлы, по которым Тео узнаёт о новых версиях. Сами файлы кладёт выпуск, руками их править нельзя. Сейчас здесь лежит `teo-update-beta.json`, описание беты 1.0.0-beta.1. Файла `teo-update-stable.json` пока нет.

Формат описаний версий записан здесь. Тео читает их раз в сутки.

## Какие бывают

| Файл | Для кого |
|---|---|
| `teo-update-stable.json` | все люди |
| `teo-update-beta.json` | те, кто проверяет новые версии первыми |

## Как устроен файл

Это обёртка из четырёх полей:

```
{ "v": 1, "kid": "<имя ключа>", "payload": "<base64url от JSON>", "sig": "<подпись Ed25519>" }
```

- `kid` это имя ключа, которым подписано описание. Ключ обновлений свой, не ключ пропусков.
- `payload` это содержимое описания, записанное в base64url.
- `sig` это подпись Ed25519. Она считается над байтами `payload` так, как они лежат в файле.

## Что внутри payload

После расшифровки это JSON с такими полями:

| Поле | Что это |
|---|---|
| `product` | всегда `teo` |
| `channel` | `stable` или `beta`, как в имени файла |
| `version` | номер версии, например `1.0.1` или `1.0.1-beta.2` |
| `released_at` | время выпуска по UTC, например `2026-11-12T10:00:00Z` |
| `installer` | `name`, `size` в байтах, `sha256` и `urls` со списком адресов `https` |
| `notes` | список строк «что нового» для людей |

Имя установщика строго `Teo-Setup-<версия>.exe`. Адрес установщика в `urls` ведёт на вложение релиза `v<версия>` в этом репозитории.

## Что проверяет Тео

- Подпись ключом, который вшит в программу.
- Канал совпадает с каналом человека.
- Версия строго выше установленной. Порядок такой: `alpha`, `beta`, выпуск.
- Дата выпуска не раньше последней виденной. Старое описание второй раз не принимается.
- Файл описания не больше 64 КБ.
- Сумма SHA-256 и размер установщика сходятся с описанием.

Откат версии невозможен. Ошибку выпуска исправляет новая версия выше.

## Порядок выкладки

1. Загрузить установщик во вложения релиза `v<версия>`.
2. Положить файл канала в эту папку.

Сначала установщик, потом описание. Иначе человек увидит версию, которой ещё нет для скачивания.
