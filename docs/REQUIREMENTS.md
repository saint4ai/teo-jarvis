# Системные требования

[English version](REQUIREMENTS.en.md) · [Назад к README](../README.md)

Два уровня. **Минимальные:** Тео работает в лёгком режиме, часть функций проще. **Рекомендуемые:** всё включено.

## Windows

| | Минимум | Рекомендуем |
|---|---|---|
| Система | Windows 10 (1809 и новее) или Windows 11, 64 бита | Windows 11 или Windows 10 22H2, 64 бита |
| Процессор | 4 потока, набор команд AVX2. Ориентир: Intel Core 8-го поколения и новее, AMD Ryzen | 4 ядра и 8 потоков (Core i5 8-го поколения и новее, Ryzen 5) |
| Память | 8 ГБ | 16 ГБ |
| Диск | 3 ГБ свободно | 5 ГБ свободно на SSD |
| Микрофон | любой рабочий | гарнитура, если в комнате шумно |
| Интернет | постоянный доступ к Claude | устойчивое соединение |
| Видеокарта | любая с DirectX 11 | встроенная Intel UHD 620 и новее или отдельная |

Intel Celeron и Pentium с 2018 по 2020 год ниже минимума: у них нет AVX2.

## macOS

| | Минимум | Рекомендуем |
|---|---|---|
| Система | macOS 13 и новее | macOS 15 и новее |
| Процессор | Apple M1 и новее. Mac на Intel не поддерживается | Apple M1 и новее |
| Память | 8 ГБ | 8 ГБ |
| Диск | 3 ГБ свободно | 5 ГБ свободно |
| Микрофон | встроенный подходит | гарнитура в шумной комнате |

macOS спрашивает разрешения по одному, в момент первой нужды: микрофон (обязательно), управление устройством (кнопка Тео, окна, ввод текста), запись экрана, автоматизация и уведомления (по желанию).

## Что ещё нужно

- Подписка Claude Pro или выше, или свой ключ API Anthropic.
- Для казахского языка и облачного голоса: свой ключ ElevenLabs (по желанию).
- Ставить заранее ничего не нужно: ни Python, ни Node.

## Как Тео проверяет компьютер

При первом запуске и по кнопке «Перемерить компьютер» в Настройках: до 10 секунд, без звука и окон. Тео называет один из трёх уровней: рекомендуемый, минимальный, ниже минимума. Бета не начинается на компьютере ниже минимума: Тео честно скажет почему.
